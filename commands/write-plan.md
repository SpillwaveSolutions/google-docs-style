---

Write a plan using `templates/plan.md` and the `google-docs-style` skill.

Required sections:
1. Outcome
2. Scope
3. Non-goals
4. Steps (numbered)
5. Risks
6. Next action

Use second person, present tense, active voice, sentence case headings, and no em dashes.
