# Google developer documentation style

This skill directory is the Agent Plugins v1 discovery path.

Read the canonical skill at the repository root:

- [SKILL.md](../../SKILL.md)
- [Style rules](../../references/google-developer-docs-style.md)
- [Hooks](../../references/hooks.md)
- [Templates](../../templates/)

Apply the Google developer documentation style guide to every plan and document.

- Second person, present tense, active voice
- Sentence case headings and one H1
- Numbered lists for sequences
- No em dashes
- Run `python3 scripts/google_docs_style.py` on markdown output
